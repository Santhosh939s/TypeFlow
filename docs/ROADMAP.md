# 🗺️ TypeFlow Product Roadmap

Our vision is to build the fastest, cleanest, and most extensible typing practice platform on the web.

## Completed Milestones

* [x] **Core Typing Engine**: Sub-millisecond keystroke latency with international WPM standards.
* [x] **Cloud Persistence**: Supabase user profiles, personal best records, and test history.
* [x] **Community Leaderboard**: Global high-score rankings with 5-minute SWR fast caching.
* [x] **AI Weakness Trainer**: Real-time diagnostic error detection with 36 curated practice lessons.
* [x] **Daily Challenge**: Streak tracking with synchronized daily passages.

## Upcoming Milestones

* [ ] **Multiplayer Race Mode**: Real-time WebSocket typing races with live track animations.
* [ ] **Custom Text Upload**: Support for custom user-uploaded books and study passages.
* [ ] **Discord Rich Presence**: Share live speed and test records on Discord profiles.
