# ⌨️ TypeFlow Keyboard Shortcuts Guide

TypeFlow is built for keyboard-first navigation and high-speed typing practice.

## Core Navigation Shortcuts

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>Tab</kbd> + <kbd>Enter</kbd> | **Restart Test** | Resets the current test with a fresh passage immediately. |
| <kbd>Esc</kbd> | **Quick Pause / Restart** | Halts current session and returns caret to starting position. |
| <kbd>Ctrl</kbd> + <kbd>+</kbd> | **Zoom In** | Zoom in natively without interfering with typed text. |
| <kbd>Ctrl</kbd> + <kbd>-</kbd> | **Zoom Out** | Zoom out natively without capturing key events. |
| <kbd>Ctrl</kbd> + <kbd>0</kbd> | **Reset Zoom** | Resets browser zoom level to 100%. |

## In-Test Controls

| Key | Behavior |
| :--- | :--- |
| <kbd>Space</kbd> | Submits the active word and advances caret to the next word. |
| <kbd>Backspace</kbd> | Corrects current word characters. |
| <kbd>Ctrl</kbd> + <kbd>Backspace</kbd> | Clears the entire current word buffer. |

## Post-Test Shortcuts

* <kbd>Tab</kbd> or <kbd>Enter</kbd>: Advance immediately to the next test.
* <kbd>Esc</kbd>: Dismiss result modal.
