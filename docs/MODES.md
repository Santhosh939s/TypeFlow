# 🎯 TypeFlow Practice Modes Guide

TypeFlow offers versatile practice modes tailored for casual typists, software engineers, and competitive speedsters.

## Available Modes

1. **Time Mode (`time`)**:
   * Timed sprints: 15s, 30s, 60s, or 120s.
   * Focuses on sustained velocity and consistency under clock pressure.

2. **Words Mode (`words`)**:
   * Fixed length sets: 10, 25, 50, or 100 words.
   * Emphasizes pacing and rhythm over time constraints.

3. **Quotes Mode (`quotes`)**:
   * Real literary, historical, and philosophy passages with real punctuation and capitalization.

4. **Code & DSA Mode (`code` & `dsa`)**:
   * Code snippets in JavaScript, Python, TypeScript, and algorithm challenges.
   * Features automatic indentation handling and syntax awareness.

5. **Daily Challenge Mode (`daily`)**:
   * Daily synchronized quote challenge tracking flame streaks across consecutive days.
