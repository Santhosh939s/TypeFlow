# 🤝 Contributing to TypeFlow

Thank you for contributing to TypeFlow! We welcome contributions to our open-source typing ecosystem.

## How to Contribute

1. **Fork or Clone the Repository**:
   ```bash
   git clone https://github.com/Santhosh939s/TypeFlow.git
   cd TypeFlow
   npm install
   ```

2. **Create a Dedicated Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Development Guidelines**:
   * Keep components modular and responsive across desktop and mobile devices.
   * Verify all tests and TypeScript compiler checks pass:
     ```bash
     npm run build
     ```
   * Ensure keystroke latency is unaffected by new logic.

4. **Submit a Pull Request**:
   * Push your branch to GitHub.
   * Open a PR with a concise description of your changes.
